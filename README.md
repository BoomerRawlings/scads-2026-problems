Projects 1-5 contain implementations, setup instructions, tests and technical evidence. Their product pages include demonstrations. Projects 6-9 contain clearly labeled projected solutions with detailed methodology, evaluation plans and roadmaps; implementation and evaluation have not begun.

Open a nested project to inspect its source or proposal. Original technical READMEs for implemented projects are retained as `IMPLEMENTATION.md`; publication READMEs provide current navigation. Published October 2026.

Research records distinguish authored demonstrations, measured engineering checks, development observations and projected methods. See [reproduction and data notes](PUBLICATION.md).
