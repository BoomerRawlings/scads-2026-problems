# Local pilot source review

Development cases use the known, agent-authored Cedar Basin fixture. They are
not held-out evaluations. Changing the harness after a failure is development,
not a new independent trial of the unchanged system.

Review original `report.json`, trace, ledger and metadata. Keep the model's JSON
unchanged, even if rejected. A separate review file records findings; rerendering
Markdown may repair links but must not silently rewrite analytic claims.

## Riverwatch acceptance

| Criterion | Source-grounded expectation |
| --- | --- |
| Scope and identity | Investigate Riverwatch Pilot and relevant dependencies; do not include the unrelated arts event or transfer its status to the institute. |
| Readiness | Preserve the September 3 ready register and September 5 delayed review. Explain their dates and unresolved reconciliation; recency alone does not prove correction. |
| Dependency path | Cite Riverwatch → Silt Sensor Batch → Northline. Pending acceptance/calibration is not proof of defective sensors. |
| Shipping | Preserve September 14 and September 19 planned arrival dates with their sources. Neither establishes actual receipt. |
| Actual media | Trace includes successful source-pixel calls. Compare every claimed observation against independently decoded image/frame pixels. Locators identify actual returned frame PTS, not merely requested seek offsets. |
| Independence and gaps | Caption media and associated text share authored provenance. Missing raw inspection-tag media, sampled video coverage, synthetic scope and absent real-world verification remain explicit where relevant. |
| Citation support | Check every finding/conflict against cited source text, not only whether an ID exists. Distinguish evidence statements from inference. |
| Reproduction | Preserve exact target/question, model/runtime manifest, code/data fingerprints, settings, elapsed time, failures/rejections, trace and evidence ledger. |

A technically valid JSON report can fail this review. Report separately whether
the software accepted it, whether source review accepted its analysis, and which
limitations remain. Independent AI review is not independent human labeling.

## Delta acceptance

The ambiguous alias must retain both candidate identities, request clarification,
and avoid investigating an arbitrarily selected candidate. Citation and media
arrays remain empty when no source evidence was retrieved. Evaluate narrative
quality separately from correct abstention behavior.

## Interpretation

These cases demonstrate particular workflow behaviors. No success-rate estimate,
general factual-accuracy claim, natural-scene benchmark, or analyst-time saving
follows from them. Runtime measurements include other active local workloads.
The direct-pixel probe is a separate caption-transcription check, not a substitute
for a completed agent investigation.
