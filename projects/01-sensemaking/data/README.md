# Synthetic sensemaking corpus

All organizations, events, claims, role labels, and dates were generated by coding
agents for this project. This is an authored demonstration and regression fixture, **not an
independent benchmark**. Expected retrieval sets encode this fixture's graph
semantics; scores on it do not establish performance on real organizations.

Main question: **What evidence affects Riverwatch readiness, including its
dependencies?**

- `graph.json`: 10 entities; directed `contains`, `depends_on`, and `supplied_by`
  edges. Each edge cites supporting fixture source IDs.
- `records.csv`: 7 structured sources, each with one normalized assertion.
- `manifest.json`: 9 local text sources with relative paths and explicit
  assertions. IDs remain stable across loading, retrieval, and citation.
- `annotations/`: authored synthetic annotations, not OCR or model extractions.
- `transcripts/`: authored synthetic transcripts, not speech recognition.
- `media/`: one generated PNG planning board and one 30-second, caption-only
  MP4 linked to `img-note-001` and `video-tx-001`. The pixels are rendered from
  authored fixture text, so they are not independent corroboration. The agent's
  `read_media` tool opens real image pixels and decodes selected MP4 frames.
  No recorded people or audio. Other media records have no attached raw source.
- `ground_truth.json`: 7 authored expected retrieval cases. Compare
  evidence IDs and conflict `(subject, predicate)` pairs as unordered sets.

## Deliberate challenges

The institute contains divisions, teams, and projects. Riverwatch is three
containment hops below `cbri`; `silt_sensors` and external supplier `northline`
are four and five hops below it. From `riverwatch`, those dependencies are one
and two hops away. Traversal follows outgoing edges only. Inclusion means an
evidence record's linked entity is reachable; a name mentioned in its prose
does not create another graph link.

`tbl-003` records Riverwatch readiness as `ready`; later `memo-001`,
`img-note-001`, and `video-tx-001` say `delayed`. `tbl-006` records expected
arrival as September 14; later `memo-004` says September 19. These are dated
claim disagreements, which may reflect updates or stale records. Display the
dates and both claims; do not silently treat the newest source as verified
truth. Multiple authored sources are not independent corroboration.

`tbl-007` deliberately mentions Riverwatch but belongs only to
`arts_collective`. It must not be retrieved for the environmental project.
The alias **Delta** maps to both `delta_team` and `arts_collective`: entity
resolution must abstain or request a more specific name. The seven standard
retrieval cases use unambiguous targets; test `Delta` separately as ambiguous.

ClearAir has no outgoing dependency links. Lack of a link in this small corpus
does not establish universal independence. The Riverwatch concern remains
scoped to that project; containment does not transfer delay, fault, or guilt to
every ancestor or sibling. No performance statistics are embedded in the data.

Regenerate the small media files with `python scripts/build_media.py` from the
project directory; requires Pillow and ffmpeg. The indexed annotation/transcript
headers describe how their text was authored, not whether a later agent has
inspected the generated media. Actual media observations belong in the run report.
