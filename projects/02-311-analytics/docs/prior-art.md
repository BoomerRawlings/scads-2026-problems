# Prior art and reuse decisions

Research date: **2026-10-06**. Primary documentation and source inspection; nothing installed or executed. “Runnable” means implementation and launch instructions exist, not that we validated a deployment. Rolling documentation may exceed features in an older installed Elastic version.

Recommendation: imitate Elastic's schema-aware, parameterized tools; Wren's explicit metric definitions; Vanna's separate data artifacts and UI results. Keep Elasticsearch queries, Maps filtering, and CSV export independent of whichever agent/model is selected later.

[Dashboard documentation](https://www.elastic.co/docs/explore-analyze/ai-features/agent-builder/agent-builder-dashboards-and-visualizations) demonstrates interactive ES\|QL/Lens and Vega-Lite panels. | Requires appropriate [subscription/tier](https://www.elastic.co/docs/explore-analyze/ai-features/agent-builder/get-started). [Chat Dashboard source](https://github.com/eosphoros-ai/DB-GPT/blob/ad203de5c7301c9a103caa1198d17aaee18c6647/packages/dbgpt-app/src/dbgpt_app/scene/chat_dashboard/chat.py) executes chart SQL and preserves query, columns, values, and description. | Dashboard path is SQL-based; broader framework also executes code. Elasticsearch retrieval/vector-store integration does not demonstrate DSL analytics. Native Kibana Maps and downloadable CSV behavior unverified in inspected path. Older [dashboard guide](https://github.com/eosphoros-ai/DB-GPT/blob/ad203de5c7301c9a103caa1198d17aaee18c6647/docs/docs/application/apps/chat_dashboard.md) uses v0.6 screenshots; match examples to pinned source. | **Imitate** query/result provenance and reusable report schema. **Avoid** importing its whole workflow platform or arbitrary code execution for this focused demo. |

The reusable design is a provider-neutral tool contract: discover schema → validate analytical request → execute bounded Elasticsearch operations → return evidence, map state, and an export reference. This recommendation is our synthesis, not an upstream guarantee. None of these sources demonstrates the complete NYC 311 acceptance case or validates million-record performance for our deployment.

Before any code reuse, pin the revision and inspect its file/dependency licenses; retain required notices. No third-party code copied in this research pass.
