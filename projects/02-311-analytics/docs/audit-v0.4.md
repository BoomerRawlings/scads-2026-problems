# v0.4 implementation audit

The audit found repeated work, deadline gaps and resume-integrity failures. Fixes stay within the existing agent-neutral service, bounded reference executor and Elasticsearch adapters. Complexity review found no justified dependency replacement or broad abstraction removal.

- **Reference execution:** prepare date operands, membership sets and polygon coordinates once per scan; retain closure durations only when requested; sort once for both percentiles. Query preparation remains local to each execution, so later source/spec changes remain visible. Oversized JSONL lines now fail before decoding; blank lines consume the deadline; malformed/deep JSON returns a typed failure. Existing instant, missing-value, polygon-boundary and statistical semantics remain covered. [Implementation](../analytics311/fixture.py), [regressions](../tests/test_fixture_optimization.py).
- **Analysis and CSV:** one absolute deadline spans validation, both comparison periods and final processing. Exports receive their export deadline instead of silently inheriting the shorter analysis budget. CSV SHA256 accumulates over emitted UTF-8/BOM bytes, avoiding a second file read; aggregate export avoids a duplicate row list. Saved-result retrieval reads JSON once while retaining identity checks. [Implementation](../analytics311/service.py), [regressions](../tests/test_execution_hardening.py).
- **Elasticsearch/configuration:** composite bucket counts must reconcile with the exact matched population before claiming completion. Missing/malformed records, dimensions, counts and aggregations fail explicitly; malformed endpoint/profile settings return configuration errors. Export selection compiles once across PIT pages. These checks have local fake-transport evidence; live compatibility remains unverified. [Backend](../analytics311/elastic.py), [regressions](../tests/test_execution_hardening.py).
- **Ingestion:** version-2 checkpoints bind source/index identity to hashes of both acknowledged bytes and a pending attempted bulk. A failed request can have written some records, so checking only the acknowledged prefix is insufficient. Resume checks both prefixes and JSONL boundaries; changed input cannot silently produce a completed mixed snapshot. Each normalized row is encoded once for bounded bulk transmission. **Migration:** old checkpoints cannot establish these guarantees; retain the unfinished snapshot for inspection and start a new versioned index/checkpoint. [Implementation](../analytics311/ingest.py), [regressions](../tests/test_ingest.py).
- **Capture:** sample pages reject oversized responses, duplicate/nonadvancing keys and out-of-window rows. Full capture checks time after source requests and interrupts SQLite resume reconciliation at its invocation deadline. Provider staleness and coverage restrictions remain enforced. [Sample tests](../tests/test_workloads.py), [capture tests](../tests/test_capture.py).
- **Distribution:** release artifacts stage beside the destination and publish together after verification; existing outputs are refused. Bundle assembly uses a fixed inventory, streamed hash checks and deterministic ZIP metadata; identical verified inputs produce identical bundle bytes. Inherited `PIP_*` settings are removed and pip configuration disabled for controlled build/install environments. These safeguards add no runtime dependencies. [Release tool](../tools/build_release.py), [bundle tool](../tools/package_bundle.py), [distribution tests](../tests/test_distribution.py), [bundle tests](../tests/test_bundle.py).

Measured reference performance used the same hash-verified seed-7 generated corpus: **10,000 rows, five timed executions per case**, warm filesystem cache, Windows CPython 3.12.14. Memory was measured in a separate execution. Every before/after answer SHA256 matched, including rows, totals and warnings. Full specs, hashes and individual measurements: [before](../examples/evidence/fixture-before-v0.4.json), [after](../examples/evidence/fixture-after-v0.4.json).

Count-only peak Python allocation fell from **298,022 to 18,404 bytes: 93.8% lower**. This is `tracemalloc` allocation evidence, not process RSS. Date membership returned zero matches; positive offset-equivalent matches have separate regression tests. Concurrent desktop load was uncontrolled. These measurements establish bounded reference behavior only: no Elasticsearch throughput, NYC conclusions, tail-latency guarantee or million/billion-row extrapolation. [Measurement tool](../tools/benchmark_fixture.py).

The [full rerun](../examples/evidence/test-report-v0.4.json) collected **326 tests: 325 passed, one Windows privilege-dependent skip, zero failures/errors**. The [initial run](../examples/evidence/test-report-v0.4-initial.json) had one export worker remain running beyond the interface test's 60-second timeout. All four interface tests then passed in isolation, followed by the full passing rerun, without runtime or timeout changes. Cause remains unconfirmed; the initial failure is retained.

Final [core](../examples/evidence/release-core-v0.4.json) and [agent](../examples/evidence/release-agent-v0.4.json) packages passed clean offline installation outside the checkout, including actual CSV workers and transferred tools. The agent package also passed MCP/geometry checks. Parent verification matched all packaged runtime/resource bytes to frozen source and checked every ZIP entry against its CRC/SHA256 inventory. [Transfer receipts](../examples/evidence/handoff-bundles-v0.4.json), [installation](distribution.md).

Remaining gates: live Elasticsearch/Kibana API and rendered-map parity; at least **2 million real unique requests** with independently qualified coverage and official geography; held-out agent evaluation (40 questions × 3, including a second client); physical scaling/failure measurements on documented hardware; fully offline model/map/assets execution. Simulated sizing, authored fixtures, source samples and measured engine workloads remain separate evidence classes. [Acceptance criteria](acceptance.md).
