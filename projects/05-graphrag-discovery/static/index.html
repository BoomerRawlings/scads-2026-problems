Quick start

  1. Open Explore. Choose a corpus and a published snapshot.
  2. Type a research question. Live preview traces matching evidence as you type.
  3. Select Search evidence to retain results. Open a finding or graph edge to read its exact source.
  4. Use Compare to review changes, or Investigations to save your question and notes.

With the included pump-fixture corpus, try Pump P. Its sources and assertions are authored examples.

Read the graph

Circles represent entities; arrows represent retrieved relationships. Dashed arrows are planned relationships; disputed ones are marked separately. Dotted preview links connect relationships to source revisions.

In preview, select a node, link, or source to trace support. After Search, select nodes as baseline seeds. The graph shows a retrieved subset, not the entire corpus.

Preview and search

Preview uses local keywords, including a partial final word. It creates no saved run and calls no model. Search evidence uses your selected retrieval method.

Press Esc in the question field, clear it, or toggle Live preview off to restore your preceding analysis. Reduced-motion settings disable animation.

Choose a time

Under Time & model controls, Known by limits when evidence was available to the system. Applies at filters reported or planned event intervals in graph mode.

Use UTC timestamps, such as 2025-02-02T00:00:00Z. Blank fields use the snapshot boundary with no event-time filter. Snapshot history tracks publication, not world events.

Compare changes

Run a search, select findings or graph seeds, then open Compare and Save current baseline. Choose a target snapshot and comparison mode.

  • Knowledge change: newly available support within the same event scope.
  • Source revisions & withdrawals: changes to sources behind saved findings.
  • World state: compare two event times at one knowledge boundary; requires graph evidence with known intervals.

Inspect both source versions. A withdrawal does not establish that a real-world relationship ended; a plan remains a plan.

Save and export

In Investigations, enter a title, question, and notes, then save. Reopening restores the saved evidence run and selections. Notes are your observations, separate from source facts.

Export evidence downloads the current search or comparison as a ZIP with findings, provenance, and scope. Preview must become a Search before export.

Add sources

In Import sources, provide a corpus ID, a unique idempotency key per batch, and public-text document-version JSONL. Stage the batch, inspect rejected records, then publish a snapshot. Browser requests are limited to 1 MiB.

Graph relationships require authored assertions or extraction through the local-model CLI before publication. Raw text alone supports source-passage search. Select the published corpus and snapshot in Explore.

Local models and troubleshooting

Lexical search and the authored demo need no model. Dense/hybrid search requires a local llama.cpp embedding server and a vector index built through the CLI. Use the same database as the running workspace, then Refresh and select the index under Time & model controls. No paid API is required.

For command options, run these in your installed Python environment:

python -m graphrag_discovery extract --help
python -m graphrag_discovery index-vectors --help

No results? Check the snapshot, time filters, and retrieval mode. Connection unavailable? Start the local workspace service, then Refresh. A partial result means a query limit was reached; inspect Scope, coverage & execution.
